Gmarket Sans (TTF) -- the font used by the pptblue beamer theme.

Files
  GmarketSansTTFMedium.ttf   body text (used by the theme)
  GmarketSansTTFBold.ttf     bold text (used by the theme)
  GmarketSansTTFLight.ttf    not used by the theme; kept for completeness
  OFL.txt                    license text, copied verbatim from the font files' metadata

Source
  Official free distribution by Gmarket: https://www.gmarket.co.kr/corp/gmarketsans
  The files are the unmodified originals (Version 1.000).

The theme looks for the two .ttf files directly in this folder (not in a subfolder).
If they are missing, it falls back to Noto Sans CJK KR, then UnDotum.
